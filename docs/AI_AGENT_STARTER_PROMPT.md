# AI Agent Starter

Это короткая active entry point для любого AI coding agent.

1. Прочитать [`AGENTS.md`](../AGENTS.md) — единственный общий workflow authority.
2. Прочитать [`docs/README.md`](./README.md) — карта документации, ownership и lifecycle.
3. Открыть только 1–3 task-specific sources, необходимые для текущей задачи.

Не использовать этот файл как источник branch/PR, CI, security, architecture, API, RBAC или product rules. Такие правила принадлежат `AGENTS.md`, task-specific docs и canonical owner-sources.
