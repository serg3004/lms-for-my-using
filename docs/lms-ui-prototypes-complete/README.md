# LearnSpace UI prototypes

Автономные HTML-прототипы интерфейса LMS. Они служат UX-ориентиром для разработчиков и AI-агентов, но не являются production-кодом.

## Правила использования

1. Перед изменением интерфейса найдите маршрут в `manifest.json`.
2. Откройте соответствующий HTML-прототип.
3. Сравните прототип с актуальной реализацией приложения.
4. Не копируйте HTML напрямую в production-код.
5. Сохраняйте текущую структуру, визуальный язык и локализацию `RU / EN / KK / ZH`.
6. Любые расхождения между прототипом и кодом приложения фиксируйте явно.

## Структура

- `public/` — публичные и системные страницы.
- `learner/` — интерфейс ученика.
- `admin/` — административный интерфейс.
- `manager/` — интерфейс менеджера.
- `instructor/` — интерфейс инструктора.
- `manifest.json` — соответствие маршрутов и файлов.

## Технические свойства

- каждый файл полностью автономен;
- внешние CSS/JS-зависимости отсутствуют;
- выбор языка сохраняется в `localStorage` под ключом `lms-prototype-language`;
- интерактивные действия являются демонстрационными;
- браузерный визуальный рендер в исходной среде не выполнялся.

## Для AI-агентов

Используйте эти прототипы как источник UX-контекста. Перед реализацией обязательно прочитайте актуальные файлы приложения и следуйте архитектуре проекта. При конфликте production-кода и прототипа не делайте предположений: зафиксируйте расхождение и уточните требуемое поведение.
