# Диктовка и звук в комментариях чек-листов

> **Статус:** `CURRENT PROCEDURE` (PR 513). Описывает, что включено, лимиты, как отключить и куда уходит звук. Матрица приёмки разрывов 85–89 внизу.

## Что включено по умолчанию

- **Диктовка** (кнопка «Диктовать» рядом с полем комментария) включена: колонка `organizations.dictation_enabled` = true. Это распознавание речи самим браузером, на сервер ничего не отправляется.
- **Запись звука** выключена: `organizations.voice_notes_enabled` = false. Администратор включает её в «Безопасность → Диктовка и звук в комментариях чек-листов».
- У каждого чек-листа режимы `dictationMode` и `voiceNotesMode` по умолчанию «наследовать». Действует то, что разрешила организация и что не выключил чек-лист («Выключено» сильнее). Чек-лист не может включить то, что выключено в организации.

## Лимиты

- Длина одной записи: по умолчанию 120 секунд (`voice_note_max_seconds`), не короче 0,3 секунды.
- Записей на один комментарий: по умолчанию 3 (`voice_notes_per_comment`). Замена записи в лимит не входит.
- Размер файла до 4 МиБ, форматы webm, ogg, mp4; формат проверяется по содержимому, а не по расширению.
- Сервер отвечает: 403 — запись выключена, 400 — слишком длинная, 409 — больше лимита.

## Куда уходит звук

- **При диктовке** звук обрабатывает распознавание речи браузера. В Chrome и Edge оно может отправлять звук на сервер производителя браузера; наш сервер получает только готовый текст. В Firefox кнопки нет.
- **При записи звука** файл хранится в закрытом хранилище и отдаётся только через API (`/checklist-instances/:id/voice-notes/...`), прямой ссылки на хранилище нет. Слышат его сотрудник-автор, проверяющие и наблюдатели с правом на отчёт. Запись из чужой организации недоступна. Гость по ссылке может записывать только ответ.
- Заголовок `Permissions-Policy` разрешает микрофон только самой странице (`microphone=(self)`): в `infra/nginx/security-headers.conf` и в `apps/api/src/common/middleware/api-hardening.ts`. Камера и геолокация закрыты. Не менять на `microphone=()`: кнопки диктовки и записи перестанут работать.

## Как отключить

1. Всей организации: «Безопасность → Диктовка и звук…» — выключить запись звука и/или диктовку. Действует со следующего запроса, без нового входа. Уже сделанные записи слушаются и удаляются, новых нет.
2. Одному чек-листу: в конструкторе «Что видит сотрудник» выбрать «Выключено» для диктовки или записи звука.
3. Аварийно, если экран недоступен:

   ```sql
   UPDATE organizations SET voice_notes_enabled = false, dictation_enabled = false WHERE id = '<organization-id>';
   ```

4. Удалять таблицу `checklist_voice_notes` и откатывать миграции нельзя: записи будут потеряны (`MIGRATION_BACKUP_POLICY.md`).
