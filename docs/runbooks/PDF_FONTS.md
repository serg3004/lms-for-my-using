# Шрифты PDF-отчётов

PDF детального отчёта сессии (`GET /checklist-sessions/:id/report.pdf`, PR 372) печатает текст на русском, английском, казахском и китайском. Шрифты подключаются из npm-пакетов, отдельных файлов шрифтов в репозитории нет.

## Состав и лицензии

| Пакет | Что покрывает | Лицензия |
| --- | --- | --- |
| `@fontsource/noto-sans` | латиница, кириллица (включая казахские Ә Ғ Қ Ң Ө Ұ Ү Һ І), греческий, вьетнамский | SIL Open Font License 1.1 |
| `@fontsource/noto-sans-sc` | китайские иероглифы (упрощённые), знаки препинания CJK | SIL Open Font License 1.1 |

Начертания: обычное (400) и жирное (700). Текст лицензии лежит в пакетах (`LICENSE`); OFL разрешает встраивание шрифта в PDF и распространение вместе с приложением при сохранении лицензии. Шрифты не изменяются.

## Как выбирается шрифт

Оба пакета отдают шрифт уже нарезанным на подмножества по диапазонам Unicode (`unicode-range` в `400.css` и `700.css`). `checklist-report-pdf-fonts.ts` читает эти диапазоны и для каждого символа выбирает файл подмножества; побеждает последнее правило `@font-face`, как в браузере (диапазоны пересекаются, например U+04B0). В документ попадают только нужные подмножества, поэтому файл с кириллицей весит десятки килобайт, а иероглифы подгружаются кусками.

Символ, которого нет ни в одном подмножестве, печатается знаком «?», а не пустым «квадратом». Языка файла для выбора шрифта не нужно: выбор идёт по символам, поэтому китайский комментарий в русском отчёте тоже читается.

## Образ API

`@fontsource/noto-sans-sc` добавляет около 74 МБ в `node_modules` образа API (подмножества хранятся в `woff`). Это единственная плата за поддержку китайского языка; если размер образа станет проблемой, пакет можно заменить подмножеством под иероглифы интерфейса, не меняя код выбора шрифта.

## Проверка

- `checklist-report-pdf-fonts` проверяется в `checklist-session-report-pdf.spec.ts`: кириллица, казахские буквы и иероглифы остаются без замены, символ вне покрытия становится «?».
- Для ручной проверки откройте PDF сессии с комментарием на каждом языке и убедитесь, что нет пустых квадратов.
- Обновление пакетов шрифтов: после `pnpm update` повторите тест; формат `400.css`/`700.css` (блоки `@font-face` со строкой `unicode-range`) должен сохраниться.
