# Визуальные правила: «Мягкая + индиго»

**Основание:** PR 565 ([`VISUAL_REFRESH_PLAN.md`](../../archive/completed-plans/VISUAL_REFRESH_PLAN.md)), выбор владельца 2026-11-23: направление «C + индиго».
**Статус:** правила утверждены владельцем; код не меняется до слова «Выполняй PR 566».
**Для кого:** PR 566–570 и все новые экраны (в том числе PR 563, 564, 527).

## Выбранное направление

Мягкая форма: крупные скругления, больше воздуха, карточки без рамок, иконки с лёгкой заливкой. Цвет остаётся фирменным индиго (основной цвет приложения), боковое меню тёмное, как привычно пользователям.

Отвергнуто: A «Спокойная» (слишком близко к текущему виду), B «Рабочая» (плотные таблицы и светлое меню), C с зелёным акцентом (смена фирменного цвета).

## Правила

1. **Поверхности.** Карточка без рамки, с мягкой тенью; карточку внутри карточки не делаем. Разделение строк таблицы едва заметной линией или пустым местом. Шапка страницы без нижней черты.
2. **Кнопки.** На странице одна главная кнопка (индиго). Остальное вторичные кнопки без рамки с лёгкой тенью или пункты меню «Ещё». Не больше двух видимых кнопок рядом с главной.
3. **Иконки.** Один набор линейных иконок: толщина линии одинакова на всех экранах, у пунктов бокового меню лёгкая заливка. Размер 20 px в меню, 16–18 px в кнопках и таблицах. Иконка всегда сопровождается подписью, кроме меню «⋯».
4. **Типографика.** Заголовок страницы крупный, с лёгким сжатием букв; подзаголовок серый; метки разделов мелкие заглавные. Названия страницы, раздела и панели различаются размером и весом заметно.
5. **Формы и фильтры.** Фильтры сворачиваются в один ряд: поиск плюс выпадающие кнопки; быстрые статусы фишками. Поля формы сгруппированы по смыслу, подпись над полем.
6. **Метки статусов.** Таблетки в одну строку, без переноса текста; цвета статусов не зависят от цвета бренда.
7. **Телефон.** Широкая таблица на узком экране не прокручивается вбок: строка превращается в карточку (название и сведения слева, статус справа одной строкой). Кнопки и фильтры не занимают весь первый экран.
8. **Пустые состояния.** Короткое объяснение и одно действие, без больших пустых блоков.
9. **Тёмная тема.** Те же правила; индиго светлеет, чтобы контраст текста был не ниже AA.
10. **Ограничения.** Бюджет стилей, общие стили админки и старые данные (см. PR 566): новые правила вводятся через переменные оформления, а не через заплатки.

## Как проверять

Интерактивный макет выбранного направления показан владельцу в PR 565 (экраны «Список сессий» и «Дашборд», светлая и тёмная тема, компьютер и телефон). Приёмка в PR 570: снимки до и после, контраст, телефон, четыре языка.
