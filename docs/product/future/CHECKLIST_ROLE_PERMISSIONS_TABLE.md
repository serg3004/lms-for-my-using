# Права и роли модуля «Чек-листы» — таблица владельца

Эталон прав от владельца (2026-10-27) и единственный файл таблицы в репозитории (решение владельца 2026-10-28: `.xlsx` удалён). Столбец «Статус» показывает, совпадает ли текущий код: «реализовано» или «план: PR N» (PR из `CHECKLIST_ROLE_PERMISSIONS_PLAN.md`, PR 359–367). Машиночитаемая копия — `apps/api/src/modules/checklists/checklist-role-permissions.table.ts`; тест `checklist-role-permissions.parity.spec.ts` сверяет её с этим файлом и с `rolePolicies`, поэтому правьте оба файла вместе.

«Своя команда» — сотрудники основного подразделения руководителя. ² — сотрудник видит только свои сессии; результат и обратная связь по настройке «Когда сотрудник видит обратную связь».

Статус «реализовано»: роли, которым код разрешает действие, совпадают со столбцами таблицы. «План: PR N»: код отличается от таблицы или действия в коде ещё нет, исправление в указанном PR; поведение API в PR 359 не менялось.
