# План: вкладка «Аналитика» на странице «Чек-листы», аналитика по выбранному листу и вход в лист по ссылке и QR (этап 10)

**Основание:** запросы владельца 2026-11-10: (1) аналитика (скриншоты страницы «Чек-листы»: место вкладки рядом с «Чек-листы», «Сессии», «Оценочные шкалы» и место кнопки в панели выбранных листов); (2) вход в лист со «Свободным прохождением» по ссылке и QR-коду, в том числе без регистрации (скриншоты редактора листа «SLAM», вкладка «Настройки», карточка «Прохождение чек-листа»). Это новый план, два блока: аналитика (PR 459–463) и вход по ссылке и QR (PR 464–468); нумерация продолжает `CHECKLIST_EDITOR_REMARKS_PLAN_4.md` (PR 458).
**Статус:** план согласован владельцем 2026-11-10 (вопросы закрыты); ни один PR не начат. Отправка в репозиторий только по слову «отправляй».
**Цель (блок 1):** на странице «Чек-листы» есть вкладка «Аналитика»: можно смотреть аналитику по всем доступным листам или по выбранным; из списка листов отмеченный лист открывает аналитику именно по нему; метрики: процент выполнения, средний балл, распределение ответов по уровням шкалы листа (для «Да/Нет» это «Да» и «Нет», для своей шкалы её собственные уровни), сколько отвечено и сколько осталось, план и факт; для одного листа метрики можно разрезать по пунктам: критерии, группы, обратная связь, примечания.

**Цель (блок 2):** лист со свободным прохождением можно пройти по постоянной ссылке или по QR-коду (человек наводит телефон, лист открывается, он заполняет и отправляет); одним переключателем выбирается, кто может проходить: все, даже незарегистрированные, или только зарегистрированные; публичный вход защищён (код-капча, ограничение частоты, выключение и перевыпуск ссылки с предупреждением), включать его может только администратор.

## 0. Границы

- Вкладка доступна всем ролям, у которых есть права на листы (создание, просмотр, редактирование): администратор, руководитель, инструктор, наставник (`checklistsRead`, `checklistsCreate`, `checklistManagerAnalyticsRead`).
- Администратор видит аналитику по всем листам. Остальные роли только по листам, которые они создали или к которым у них есть доступ (определение в разделе «Доступ»). Права по сотрудникам не расширяются: руководитель по-прежнему видит результаты только своей команды, остальные роли по текущим правилам.
- Аналитика только читает данные: сессии, результаты и снимки листов не меняются; цвета и пороги берутся из снимков, как в отчёте сессии (PR 397).
- Существующие страницы аналитики (`/admin/checklists/analytics`, `/instructor/checklists/analytics`, `/mentor/analytics`, `/manager/checklists`) не меняются и не переадресуются (решение владельца 2026-11-10): вкладка «Аналитика» создаётся как новая страница рядом; общий код можно переиспользовать, но поведение старых страниц остаётся прежним.
- Блок 2 (вход по ссылке и QR): только для листов со свободным прохождением; настройка и любые действия с публичным входом доступны только администратору (решение владельца 2026-11-10); гость не получает учётной записи и доступа ни к чему, кроме заполнения этого листа; фото в гостевых листах по умолчанию выключены.
- Все новые тексты на RU, EN, KK, ZH; слово «эталон» вместо названия стороннего продукта; бюджет CSS расходуется минимально (инлайн-стили или общие компоненты).

## Доступ

| Роль | Какие листы попадают в аналитику | Чьи результаты видны |
|---|---|---|
| Администратор | все листы организации | все сотрудники |
| Руководитель | свои листы + доступные (ниже) | только своя команда (как сейчас) |
| Инструктор, наставник | свои листы + доступные (ниже) | как сейчас (вся организация по текущим правилам) |

«Доступный лист» (решение владельца 2026-11-10): лист, который роль видит в списке «Чек-листы» (лист вне папок или в папке, открытой для сотрудников, цепочка родителей тоже видима, `visibleFolderIds`), плюс листы, по которым у пользователя есть сессии как у наблюдателя. Лист в закрытой чужой папке в аналитику не попадает.

## Метрики (определения)

- **Процент выполнения** листа: доля завершённых сессий среди запланированных и начатых в периоде (завершённые / (завершённые + в работе + не начатые + просроченные)); для критерия: доля ответов среди всех возможных ответов по сессиям.
- **Средний балл:** средний `percentage` завершённых сессий с баллами (сессии `scored = false` не входят, как сейчас); для критерия: средний балл ответа к максимуму критерия.
- **Ответы по уровням шкалы (вместо жёсткого «Нет»):** аналитика подстраивается под шкалу листа автоматически, независимо от названий уровней («Да/Нет», «Не знаю», «Частично» и любые другие). Для каждого критерия, группы и листа показывается число и доля ответов по каждому уровню своей шкалы с её названиями и цветами; у «Да/Нет» это «Да» и «Нет». При выборе нескольких листов с разными шкалами итог разбивается по шкалам отдельными блоками, уровни разных шкал не смешиваются. Дополнительно показывается число ответов с нулевым баллом (общий для любых шкал признак «не выполнено»).
- **Отвечено / осталось:** отвечено критериев (с учётом пропусков отдельной цифрой), осталось до полного заполнения; по листу суммарно по сессиям периода.
- **План / факт (оба варианта, решение владельца):** (а) план периода: число сессий, запланированных на период (`scheduledAt`) по выбранным листам; факт: из них завершённых; осталось и «просрочено» (запланировано на прошедшее время и не завершено); (б) очередь: все назначенные и ещё не начатые сессии независимо от даты, с возрастом (сколько дней ждёт); на экране два блока, переключатель не нужен.
- Фильтры: период (как сейчас `from`/`to`), подразделение, руководитель, листы; для одного листа дополнительно наблюдатель.
