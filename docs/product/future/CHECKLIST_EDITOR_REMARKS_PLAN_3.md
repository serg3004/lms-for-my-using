## PR 453 — Свой выпадающий список вместо окна браузера ✅

**Статус:** выполнен 2026-11-08 (PR с этим изменением); проверка владельцем в его Chrome (Windows) открыта. Причина: окно нативного списка рисует сам браузер, и у владельца оно без текста при верных цветах и шрифте (подтверждено двумя безуспешными исправлениями: PR 444 и #1003), поэтому исправление CSS невозможно и список теперь рисует приложение.
**Основание:** замечание 31.
**Цель:** при нажатии на любой `<select>` (мышью, Пробелом, Enter, Alt+↓) открывается панель приложения со строками-текстом, одинаковая во всех браузерах.
**Зависимости:** нет.

**Что сделано:**
- один компонент `apps/web/src/shared/SelectPopup.tsx`, подключён один раз в `main.tsx`; он перехватывает открытие любого одиночного `<select>` и рисует строки как обычные элементы страницы (`role="listbox"` и `role="option"`), поэтому ни один экран не переписывается (около 128 списков в 62 файлах), а тесты со `selectOption` работают как раньше;
- выбор записывается в сам `<select>` (значение) и отправляется событие `change`, форма и состояние экрана получают его как от нативного списка;
- в окнах `<dialog>` панель встаёт внутрь самого окна (иначе окно браузера делает остальную страницу неактивной); панель открывается вниз, а если места мало, вверх; ширина не меньше поля, не выходит за экран на 320 px; закрывается по клику снаружи, прокрутке, изменению размера, Esc, Tab;
- клавиатура: Пробел, Enter, Alt+↓ открывают; ↑ ↓ Home End двигают по доступным строкам; Enter выбирает; буквы переходят к строке с этим началом; недоступные (`disabled`) строки и группы `optgroup` поддерживаются;
- на сенсорных экранах (`pointer: coarse`) остаётся системный выбор телефона; список с `multiple`, `size` больше 1, отключённый, а также с `data-native-popup="true"` остаются нативными.

**Критерии готовности:**
- [x] окно браузера для списков не используется: строки видны как текст, подсвеченная строка с тем же шрифтом (тест e2e, Chromium);
- [x] список в обычной странице и в модальном окне «Критерий: описание и пояснение» открывается и выбирается (e2e);
- [x] клавиатура и ширина на 320 px (e2e); модульные тесты `SelectPopup.spec.tsx`;
- [x] CI зелёный;
- [ ] проверка владельцем в его Chrome (Windows), затем при желании в Edge и Firefox. Firefox и Safari в среде сборки не установлены, их проверяет владелец; так как строки рисует страница, а не браузер, различий между браузерами не ожидается.
