# План: единый современный вид приложения (этап 17)

**Основание:** вопрос владельца 2026-11-23 «нельзя ли улучшить, чтобы приложение стало эстетичнее, красивее и современнее». Нумерация продолжает PR 564 ([`LONGREAD_STANDALONE_PLAN.md`](./LONGREAD_STANDALONE_PLAN.md)).
**Статус:** план утверждён владельцем 2026-11-23, ДЕЛАЕТСЯ В ПЕРВУЮ ОЧЕРЕДЬ (раньше PR 563, 564, 527 и остальных PR редакторов); код не начат. Каждый PR стартует только по слову «Выполняй PR N».
**Цель:** у приложения один спокойный современный вид: меньше рамок и одинаковых кнопок, ясная иерархия заголовков, аккуратные таблицы и формы, хорошая тёмная тема и телефон. Работает на всех экранах, а не только в лонгриде и тестах.

## 0. Границы

- **Как есть (проверено по коду и скриншотам 2026-11-23):** в приложении уже есть система переменных оформления (цвета, радиусы, отступы, размеры текста, скорость анимации, тени), поэтому общий вид можно менять в одном месте. Вид при этом «админский»: крупные белые карточки с рамкой и тенью на каждом блоке, ряды одинаковых кнопок, заголовки панелей одного веса, отдельные строки «подпись + поле» во всю ширину. Бюджет стилей 96 КиБ почти исчерпан (занято около 94,5 КиБ, запас около 1,5 КиБ). Часть стилей лежит в файлах-заплатках (в названиях «final-alignment», «checkbox-fix»), их можно слить.
- **Решение владельца принято 2026-11-23:** направление «C + индиго» (мягкая форма, фирменный индиго остаётся), см. [`VISUAL_RULES.md`](./VISUAL_RULES.md).
- **Остаётся как есть:** логика экранов, данные, права, переводы (кроме новых подписей), порядок работы пользователей.
- **Не входит:** смена логотипа и названия, новые функции, редизайн публичной главной страницы (отдельное решение).
- Правила: тексты RU/EN/KK/ZH (длинные строки KK и RU проверяются), доступность не ниже AA, тёмная тема проверяется, старые экраны не ломаются, все изменения проходят визуальные снимки.

## PR 573 — Тёмная тема ✅

**Что сделано:** тёмные значения переменных, замена жёстких цветов в стилях и в экранах (кроме цветных градиентов, статусов с собственными цветами и QR), переключатель «светлая / тёмная / как в системе» рядом с выбором языка, маленький внешний скрипт `theme-init.js` против мигания (инлайн-скрипты запрещены политикой безопасности). **Найдено и исправлено:** настройки оформления организации всегда записывали все цвета, радиусы и тень инлайн и перебивали стили, поэтому часть правок PR 566 (фон, радиусы, тень) в приложении не была видна. - Визуальные снимки ключевых экранов в обеих темах, проверка всех четырёх языков.
