# План: единый современный вид приложения (этап 17)

**Основание:** вопрос владельца 2026-11-23 «нельзя ли улучшить, чтобы приложение стало эстетичнее, красивее и современнее». Нумерация продолжает PR 564 ([`LONGREAD_STANDALONE_PLAN.md`](./LONGREAD_STANDALONE_PLAN.md)).
**Статус:** план утверждён владельцем 2026-11-23, ДЕЛАЕТСЯ В ПЕРВУЮ ОЧЕРЕДЬ (раньше PR 563, 564, 527 и остальных PR редакторов); код не начат. Каждый PR стартует только по слову «Выполняй PR N».
**Цель:** у приложения один спокойный современный вид: меньше рамок и одинаковых кнопок, ясная иерархия заголовков, аккуратные таблицы и формы, хорошая тёмная тема и телефон. Работает на всех экранах, а не только в лонгриде и тестах.

## 0. Границы

- **Как есть (проверено по коду и скриншотам 2026-11-23):** в приложении уже есть система переменных оформления (цвета, радиусы, отступы, размеры текста, скорость анимации, тени), поэтому общий вид можно менять в одном месте. Вид при этом «админский»: крупные белые карточки с рамкой и тенью на каждом блоке, ряды одинаковых кнопок, заголовки панелей одного веса, отдельные строки «подпись + поле» во всю ширину. Бюджет стилей 96 КиБ почти исчерпан (занято около 94,5 КиБ, запас около 1,5 КиБ). Часть стилей лежит в файлах-заплатках (в названиях «final-alignment», «checkbox-fix»), их можно слить.
- **Решение владельца нужно:** визуальное направление (PR 565 покажет 2–3 варианта на макете); оставляем ли фирменный индиго как основной цвет.
- **Остаётся как есть:** логика экранов, данные, права, переводы (кроме новых подписей), порядок работы пользователей.
- **Не входит:** смена логотипа и названия, новые функции, редизайн публичной главной страницы (отдельное решение).
- Правила: тексты RU/EN/KK/ZH (длинные строки KK и RU проверяются), доступность не ниже AA, тёмная тема проверяется, старые экраны не ломаются, все изменения проходят визуальные снимки.

## PR 565 — Аудит и выбор визуального направления

**Статус:** план.
**Основание:** разрыв 139.
**Цель:** владелец выбирает направление, а не «красиво вообще».
**Зависимости:** нет.

**Что необходимо сделать:**
- Снять скриншоты 10–12 ключевых экранов на настоящих тестовых данных (компьютер и телефон, светлая и тёмная тема): список с папками, форма, редактор чек-листа, редактор теста, редактор лонгрида, чтение лонгрида, прохождение теста, дашборд, таблица результатов, вход.
- Составить список «что шумит» по каждому экрану.
- Показать владельцу интерактивный макет с 2–3 вариантами (плотность, цвета, радиусы), на реальных названиях экранов. Владелец выбирает один.
- Записать выбор в `docs/` (короткий документ о визуальных правилах).

**Критерии готовности:**
- [ ] скриншоты и список проблем показаны владельцу
- [ ] направление выбрано владельцем и записано

## PR 566 — Основа: типографика, цвета, плотность, чистка стилей

**Статус:** план.
**Основание:** разрыв 140.
**Цель:** меняется общий вид сразу везде, и это укладывается в бюджет.
**Зависимости:** PR 565.

**Что необходимо сделать:**
- Выверить шкалу заголовков (название страницы, раздела, панели заметно различаются), вес и межстрочный интервал, ширину строки текста.
- Нейтральные цвета и акцент под выбранное направление, проверка контраста AA в светлой и тёмной теме.
- Радиусы, тени и отступы: меньше рамок, тень только там, где нужно выделить.
- Слить файлы-заплатки в основные стили, удалить дубли; пересмотреть бюджет стилей осознанно (с записью причины), а не «подтянуть на 1 КиБ».
- Обновить визуальные снимки с объяснением каждого изменения.

**Критерии готовности:**
- [ ] контраст не ниже AA, тёмная тема читаема
- [ ] размер стилей в бюджете, причина записана
- [ ] снимки обновлены осознанно
