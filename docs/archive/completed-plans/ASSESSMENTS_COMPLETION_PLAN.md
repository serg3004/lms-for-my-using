## PR 583 — Список тестов и карточка вопроса по макету ✅

## PR 584 — Редактор, настройки и данные: закрытие PR 529, 530, 532, 533, 537, 538 ✅

**Статус:** выполнен (запрос владельца 2026-11-28). Решения владельца: баллы вопроса из банка принадлежат тесту, правка банка их не меняет; самостоятельный тест назначают администратор, автор и руководитель (руководитель только своей команде), а также роли и сотрудники, которых назвал автор.
**Основание:** проверка 2026-11-28; макет, вкладки «Редактор теста» и «Банк вопросов»; PR 529, 530, 532, 533, 537, 538.
**Цель:** убрать остальные отличия от макета и найденные ошибки; после PR план PR 522–538 закрыт полностью.
**Зависимости:** PR 583 (слит).

**Что добавлено:**
- Вкладка «Экраны и вид»: титульный и финальный экран и оформление вынесены из «Основное» (данные те же, потерь нет); при создании теста вкладка тоже доступна.
- Блок «Материал к вопросу» справа от списка вопросов (для открытого вопроса); «+ Из банка вопросов» последним пунктом списка добавления вместо отдельной широкой кнопки.
- «Какая попытка считается»: у нового теста по умолчанию «Лучшая попытка»; сохранённые тесты не меняются.
- Банк вопросов: список постранично по 50 (`page`, `total`, `pageSize`), кнопки «Назад» и «Далее»; папка до 500 вопросов видна целиком.
- Баллы вопроса из банка: остаются за тестом (решение владельца), правка банка их не меняет; зафиксировано в плане и в договоре API.
- Аналитика: «лидеры» и «отстающие» не пересекаются (малая группа показывает только лидеров). Пустое название подразделения уже заменялось на «Без подразделения» в интерфейсе, правка не понадобилась.
- Попытки без политики: проверка лимита и «уже идёт попытка» выполняются под блокировкой теста, два одновременных старта дают одну попытку; конец времени везде считается с `>=`.
- Право назначения: `PUT/GET /assessments/:id/standalone/grants` (роли `instructor`, `manager` и сотрудники по имени; меняют только администратор и автор); назначение и ссылку проверяет сервис, а не только роль «admin»; руководитель назначает только своей команде и ссылку без права автора не создаёт; миграция добавляет два столбца (по умолчанию пусто); в окне «Ссылка и QR» блок «Кто ещё может назначать» (4 языка).
- Документы: договор API, индекс API, статусы и галочки PR 522–538 в `ASSESSMENTS_MODULE_PLAN.md`.

**Критерии готовности:**
- [x] отдельная вкладка «Экраны и вид», старые поля удалены из «Основное» без потери данных
- [x] блок «Материал к вопросу» и пункт «Из банка» на месте (снимки 1440 и 375 px проверены)
- [x] банк постраничный, тест на папку из 120 вопросов (PostgreSQL)
- [x] тесты API: два одновременных старта не обходят лимит; лидеры и отстающие не пересекаются; права назначения (автор, руководитель, роли, сотрудники)
- [x] все статусы PR 522–538 в плане актуальны
- [x] e2e по тестам (материал вопроса, тест правок редактора) и тесты интерфейса обновлены
