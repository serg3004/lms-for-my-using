## Найденные кандидаты

### `apps/web/src/app/LogoutButton.tsx`

Компонент не импортируется ни одним файлом приложения или теста. Реальные layout-компоненты
реализуют выход самостоятельно через `apps/web/src/shared/logout.ts`, поэтому данный файл
не попадает в граф приложения.

**Что сделать:** удалить файл. Если планируется единый переиспользуемый UI-компонент выхода,
вместо простого удаления сначала подключить его в learner/manager layout и перенести туда
требуемые стили и поведение; до такого подключения файл остаётся мёртвым кодом.

### `apps/api/src/modules/auth/auth.cookies.js`

Файл содержит только реэкспорт из `./auth.cookies.ts`. При импорте
`./auth.cookies.js` TypeScript в режиме `NodeNext` явно разрешает модуль в
`auth.cookies.ts`; при сборке этот же TypeScript-файл создаёт итоговый
`dist/.../auth.cookies.js`. Исходный JavaScript-адаптер не входит в `tsconfig.json`
и не нужен ни компилятору, ни итоговому runtime.

**Что сделать:** удалить исходный `auth.cookies.js`, сохранив существующие импорты с
суффиксом `.js` — это корректное соглашение для ESM + TypeScript `NodeNext`.
